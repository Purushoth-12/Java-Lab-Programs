JAVA LAB PROGRAM: INTERFACE

Aim:
To write a Java program to demonstrate an interface.

Program (Main.java):
--------------------
interface Animal {
    void sound();
}

class Dog implements Animal {
    public void sound() {
        System.out.println("Dog barks");
    }
}

public class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.sound();
    }
}

Output:
-------
Dog barks
